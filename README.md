# ★ Памятка МВД «Арбатский»

Полевой справочник сотрудника МВД для фракции **«Арбатский»** на проекте **Russia Online** (GTA RP): статьи УК/КоАП/ПДД, права и полномочия, порядок задержания и применения силы, залоги, регламенты — и сборщик речи задержания.

**Открыть сайт:** https://youngsanifone.github.io/mvd-pamyatka/

## Что внутри

- **Быстрое задержание** — набираешь нарушения тапом по кнопкам, снизу сам собирается готовый текст: представление, статья, разъяснение прав. Одна кнопка «Копировать речь».
- **Статьи** — таблица из 95 статей УК/КоАП/ПДД по 16 категориям с поиском (по номеру, слову, синонимам с ё/й), фильтрами и легендой категорий (Н/С/Т/ОТ/адм) и розыска (★).
- **Права, Задержание, Сила, Залог, Полномочия** — краткие карточки по процессуальному кодексу и уставу.
- **Регламенты** — правила по ограблениям, похищениям и парковке на территории Управления.
- Тёмная/светлая тема, всё работает на телефоне, ничего никуда не отправляется — статичная HTML-страница на GitHub Pages.

## Твои данные

Сайт публичный — свои имя, номер жетона и подразделение каждый вводит сам при первом заходе (или через кнопку ✎ в шапке). Данные хранятся только в твоём браузере (localStorage) и никуда не передаются.

## Технически

Один файл `index.html`, без сборки и зависимостей (кроме шрифта Oswald с Google Fonts). Правки — прямо в файле через GitHub или любой редактор, деплой автоматический через GitHub Pages при пуше в `main`.
